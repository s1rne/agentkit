---
description: Завершить сессию — записать состояние для сессии с нулевым контекстом
---

Вызови `scribe`, он должен по навыку `memory-protocol`:

1. **`NOW.md`** — привести в соответствие с реальностью.
2. **`JOURNAL.md`** — запись сверху: сделано / узнали / ошиблись в / дальше. Факты и тупики, а не пересказ diff'а.
3. **`DECISIONS.md`** — новые решения.
4. **`TEAM.md`** — если менялся штат.
5. **`tasks/BOARD.md`** — пересобрать из frontmatter.
6. **`QUESTIONS.md`** и **`INBOX.md`** — перенести разобранное.
7. Документация — если реализация разошлась с описанием.

Покажи одним экраном: сделано, осталось, заблокировано.

Проверка качества: **сможет ли сессия с нулевым контекстом продолжить, прочитав только `BOOT.md`?** Нет — дописать.
