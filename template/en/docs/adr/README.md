# ADR — architecture decision records

A short document per significant decision. It exists so that a year later nobody re-argues the same points, and so an agent that lost context doesn't "improve" something chosen deliberately.

**When to write one:** the decision spans several modules, is expensive to reverse, or the argument about it runs longer than 15 minutes. A variable name is not an ADR. How tenants are stored is.

**Format:** `ADR-NNN-short-name.md`. Statuses: `proposed` → `accepted` → `superseded by ADR-NNN` / `rejected`. An accepted ADR is **never edited** — if the decision changes, write a new one linking to the old.
