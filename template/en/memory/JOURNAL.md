# JOURNAL

Append-only. Newest entries **on top**. Never rewrite or delete past ones — the journal exists so a future session sees what was already tried and why it was dropped.

```
## YYYY-MM-DD · who · what

**Done:** …
**Learned:** facts about the domain, the customer, the technology
**Got wrong:** if anything
**Next:** …
```

Record: facts, dead ends, mistakes. Don't record: a retelling of the diff — that's the git log.
