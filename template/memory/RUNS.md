# RUNS — журнал запусков агентов

Кто, когда, над чем работал и чем закончилось. Ведёт технический лид: запись открывается **перед** запуском, закрывается **после**.

Зачем: единственный способ ответить «что вообще происходит» и «почему эта задача идёт третий раз», не имея доступа к внутренностям агентов. Сюда же смотрит человек, чтобы понять загрузку без чтения всех отчётов.

Новые записи **сверху**. `режим` — `один` или `парал. N/M`. `итог` — `готово` / `частично` / `заблокирован` / `вернули` / `отменён`.

Провалы записываются так же, как успехи. Запись «вернули» с причиной ценнее трёх «готово».
