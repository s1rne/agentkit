---
description: Взять задачу в работу и провести через полный цикл до ревью
---

Возьми задачу $ARGUMENTS и проведи по циклу из навыка `team-protocol`.

1. Прочитай файл задачи. Нет `feature` или критериев — останови, позови `planner`.
2. Задача `blocked` — не бери, доложи, чем заблокирована.
3. `status: in_progress`, проставь `owner`.
4. Вызови агента из `owner`. Передай: путь к файлу задачи, критерии, нужные навыки, границы `touches`.
5. Нужны доменные тесты — вызови `qa-engineer` отдельно, **не** проси автора кода написать их самому.
6. Вызови `critic`. Вердикт `доработать`/`переделать` — верни автору, повтори.
7. `risk: high` — останови и вынеси мне на подтверждение, независимо от вердикта критика.
8. Проверь по `definition-of-done`.
9. Вызови `scribe` — журнал, `NOW`, доска.

Докладывай только на развилках и при завершении.
