# ADR — записи об архитектурных решениях

Короткий документ на каждое значимое решение. Существует, чтобы через год не переспорить самих себя и чтобы агент после потери контекста не «улучшил» осознанно выбранное.

**Когда писать:** решение затрагивает несколько модулей, его дорого откатить, или спор о нём длится дольше 15 минут. Имя переменной — не ADR. Способ хранения арендаторов — ADR.

**Формат:** `ADR-NNN-краткое-имя.md`. Статусы: `предложено` → `принято` → `заменено ADR-NNN` / `отменено`. Принятый ADR **не редактируется** — решение изменилось, пишется новый со ссылкой на старый.
