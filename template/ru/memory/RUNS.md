# RUNS — журнал запусков агентов

Кто, когда, над чем, в каком боксе и чем закончилось. Строки дописывает `agentkit run`;
запуски руками лид добавляет сам. Полный транскрипт запуска лежит в
`.agentkit/state/runs/<id>.jsonl` — этот файл указатель, а не запись.

Зачем: единственный способ ответить «что вообще происходит» и «почему задача идёт третий
раз», не читая транскрипты. Человек смотрит сюда, чтобы понять загрузку.

Новые записи **сверху**. `outcome`: `done` / `failed` / `killed` / `deferred` / `blocked` /
`refused`. Провалы записываются так же, как успехи — одна строка `blocked` с причиной
ценнее трёх `done`.
