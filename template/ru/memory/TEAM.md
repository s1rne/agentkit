# TEAM — реестр команды

Источник правды о том, **кто в штате**. Прочитав только этот файл, лид знает всю команду, не открывая определений ролей.

Меняет только технический лид, по навыку `team-composition`. Любое изменение — запись в `JOURNAL.md`.

## Два разных понятия

- **Штат** — какие роли существуют. Меняется редко, фиксируется здесь.
- **Наряд** — сколько экземпляров какой роли запущено сейчас. Считается под задачи, живёт в `RUNS.md`.

Роль — должность, а не человек: одна роль работает в нескольких экземплярах.

## Штат

Статусы: `активна` · `резерв` (определение есть, работы пока нет) · `выведена` (не использовать, файл оставлен для истории).

Заполняется командой `npx @s1rne/agentkit status` или вручную при изменении.

## Где что лежит

| Что | Путь |
|---|---|
| Определения ролей | `.agentkit/roles/<роль>.md` |
| Навыки | `.agentkit/skills/<навык>.md` |
| Кто над чем работал | `.agentkit/state/RUNS.md` |
| Изменения штата | `.agentkit/state/JOURNAL.md` |
| Правила изменения штата | навык `team-composition` |
