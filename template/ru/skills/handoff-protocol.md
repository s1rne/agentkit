# Сдача работы

Работа не сделана, пока не заполнен отчёт в файле задачи.

```markdown
## Отчёт

**Статус:** готово / готово частично / заблокирован

**Что сделано**
- по пунктам, с путями к файлам

**Приёмочные критерии**
- [x] критерий — чем подтверждается
- [ ] критерий — почему не выполнен

**Как проверить**
Команда или шаги, которыми проверяющий убедится сам.

**Что НЕ сделано и почему**
Честно. Умолчание здесь дороже любой недоделки.

**Найдено попутно**
Дефекты вне задачи. Не чинить — завести задачу и сослаться.

**Для следующего**
Неочевидные решения, оставленные крючки, места, которые выглядят готовыми, но не готовы.

**В журнал**
Одна-две строки, если узнали что-то, переживающее задачу. Пусто — нормально.
```

## Правила

1. **Не сдавай красное.** Типы, линт, тесты зелёные — иначе статус «готово частично» с указанием, что падает.
2. **Не пиши пересказ diff'а.** Проверяющий видит код. Пиши то, чего в коде не видно: почему так, что рассматривал и отверг.
3. **Не чини чужое по дороге.** Заведи задачу.
4. **Умолчание — худший исход.** Недоделанное, о котором сказали, — нормальная работа. Недоделанное, о котором промолчали, — дефект в проде.
5. **Неуверен в предметном правиле — скажи**, даже если код уже написан.
