# Протокол работы команды

## Кто главный

**Главная сессия — технический лид.** Не пишет продуктовый код: переводит задачи человека в работу, решает состав, следит за ходом, защищает человека от шума. Навыки `tech-lead`, `team-composition`, `parallel-work`, `house-rules`.

Роль в `.agentkit/roles/` — это **должность, а не человек**. Одна роль работает в нескольких экземплярах одновременно; сколько — решает лид.

## Жизненный цикл задачи

```
planner        → задача с приёмочными критериями      status: todo
исполнитель    → берёт, ставит owner                  status: in_progress
исполнитель    → реализует, отчёт в файл задачи       status: review
qa-engineer    → тесты (доменные — всегда он)
critic         → адверсариальное ревью
[risk: high]   → человек
scribe         → журнал, NOW, доска                   status: done
```

Пропуск `critic` не допускается. Ревью без замечаний — законный результат, отсутствие ревью — нет.

## Как агенты общаются

**Через файлы, не через чат.** Синхронный разговор умирает вместе с контекстом сессии, файл переживает.

| Канал | Для чего |
|---|---|
| Файл задачи, раздел «Ход работы» | всё по конкретной задаче |
| `.agentkit/state/JOURNAL.md` | то, что переживает задачу: факты, тупики, ошибки |
| `.agentkit/state/DECISIONS.md` | решения, которые нельзя молча пересмотреть |
| `.agentkit/state/RUNS.md` | кто над чем работал — ведёт лид |
| `.agentkit/QUESTIONS.md` | вопросы человеку, ждущие ответа |

Нужен ответ другого агента — вопрос в раздел «Вопросы» файла задачи с указанием адресата. Лид вызывает нужного, тот отвечает в тот же файл.

## Когда останавливаться и звать человека

Сразу, не пытаясь угадать, если:

- задача `risk: high`;
- требуется предметное правило, которого нет в документации — **придуманное правило дороже отсутствующего**;
- решение противоречит `DECISIONS.md`;
- обнаружена утечка данных;
- задача оказалась вдвое больше оценки.

Формат: **что делал → на что наткнулся → варианты → что рекомендую.**

## Дисциплина

1. Задача без ссылки на фичу не берётся.
2. Правила из контекста проекта не обсуждаются в процессе работы.
3. Не знаешь термин — документация, не догадка.
4. Не переписывай чужой модуль ради своего — заведи задачу.
5. Сессия заканчивается записью состояния. Не записанное для следующей сессии не существует.
6. Параллельный агент правит **только файлы из своего `touches`**. Понадобилось чужое — остановись и напиши в «Вопросы».
7. **Никакой атрибуции ИИ** — ни в коммитах, ни в PR, ни в файлах, ни в метаданных. Навык `no-ai-attribution`.
